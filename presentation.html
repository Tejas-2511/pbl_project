PortionVision Indian Food Identification for Automated Portion Estimation

This semester focused on the most critical bottleneck in the full PortionVision pipeline: reliable Indian food identification from real-world food images.

Problem Statement

In hostel mess environments, portion estimation is difficult because food is self-served and highly variable. Students have different calorie, protein, and dietary requirements, but without identifying the exact food, it is impossible to estimate grams, calories, or whether a meal matches their ideal intake. The earlier PBL project already developed the broader pipeline — OCR of menu data, personalized recommendations, and segmentation/depth-based mass estimation — but the main bottleneck remained the food identification stage. This is especially challenging for Indian food because of class imbalance, visually similar dishes, and multi-item plates.

Objectives

  • Build a reliable classifier for Indian food images from hostel and mess contexts.
  • Improve the food-identification stage that was the limiting factor in the previous system.
  • Use transfer learning and a practical CNN backbone to achieve strong recognition accuracy.
  • Handle a large category set while maintaining low computational cost.
  • Support real image prediction with label and confidence output.
  • Analyse weak classes and visual confusion patterns.
  • Provide a strong foundation for downstream mass, calorie, and nutrition estimation.
  • Expand the scope beyond the earlier limited food-identification setup toward a more robust system.

Literature / Existing Work

Previous PBL work

  • Built the overall PortionVision pipeline with OCR, personalized nutrition logic, and plate analysis components.
  • Identified the key limitation: the classifier was not sufficiently accurate for real Indian food categories.
  • Recognized that a robust food recognition module is essential before mass estimation can be trusted.

Relevant computer vision trends

  • Transfer learning with ImageNet-pretrained CNNs is standard for food recognition tasks.
  • EfficientNet provides a strong balance between accuracy and model size.
  • Food datasets are often imbalanced, and visually similar dishes remain a known challenge in classification.
  • Real-world food recognition is harder than benchmark datasets because of angle, lighting, clutter, and mixed plates.

Methodology

1. Dataset

The system uses the Khana dataset, containing Indian food images across a large class set. The dataset is organised by class folder and contains highly diverse food types with uneven class distribution.

2. Data split

The dataset is split into train, validation, and test subsets using a fixed random seed to ensure reproducible evaluation and reduce leakage.

3. Preprocessing

Images are converted to RGB, resized to 224×224, and normalized using ImageNet statistics so the pretrained backbone sees a familiar input distribution.

4. Model choice

EfficientNet-B0 is selected as the backbone due to its strong accuracy-to-parameter ratio. The last classifier head is replaced to match the food category count.

5. Training

Transfer learning is applied with an ImageNet-pretrained backbone. The classifier head receives a higher learning rate than the backbone, and label smoothing helps reduce overconfidence.

6. Evaluation

The classifier is evaluated using top-1 accuracy, top-5 accuracy, precision, recall, F1-score, confusion matrix, and failure analysis on difficult classes.

Conclusion

The earlier PortionVision project established the broader system architecture, but this semester focused on the critical missing component: reliable Indian food classification. By building a transfer-learning-based classifier with strong evaluation metrics and real-image prediction capability, we have created a solid foundation for the final portion estimation system. The next phase is to expand beyond the current class scope, improve weak classes, and integrate the recognition stage into full multi-food meal analysis.
